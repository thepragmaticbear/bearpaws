# Bearpaws v2.3.0 — Current Claude Code Tools & Agent Skills Install

This release aligns skills with current Claude Code tooling, adds one experimental `~/.agents/skills` install for Agent Skills agents (including OpenCode), and retires Windsurf.

## Why 2.3.0

- Claude Code renamed the subagent tool `Task` → `Agent` (v2.1.63).
- Claude Code 2.1.233 gates `TodoWrite` and `TaskCreate`/`TaskUpdate`/`TaskGet`/`TaskList` off for current models (Opus 4.8+, Sonnet 5+, Fable 5+). Skills that required them gave instructions the agent could not follow.
- Codex, Devin, OpenCode, and other agents now scan `~/.agents/skills/`.

## What changed

### Claude Code tool alignment
- Subagent dispatch text and prompt templates now name the `Agent` tool (formerly `Task`).
- `executing-plans` and `subagent-driven-development` track progress with the plan's checkboxes, and use a task-tracking tool only if one is available.
- The Antigravity capability map, `docs/skill-structure.md`, and `docs/testing.md` reflect the new names.
- Claude Code tests accept both `Agent` and `Task`, and count any progress tracking: `TodoWrite`, `TaskCreate`/`TaskUpdate`, or a checked plan box.

### Installer fixes
- `create_symlinks` now removes only broken links. Previously, a single broken link wiped every symlink in the target, which was destructive for shared directories like `~/.agents/skills`.
- `((failed++))` → `((++failed))` so a failed platform reports its error instead of exiting silently under `set -e`.
- `tests/install/run-install-tests.sh` is now executable.

### Cleanup (ponytail audit)
- Removed 4 unreferenced one-off repro scripts from `tests/explicit-skill-requests/` (`run-haiku-test.sh`, `run-multiturn-test.sh`, `run-extended-multiturn-test.sh`, `run-claude-describes-sdd.sh`). `run-all.sh` and `run-test.sh` remain.
- Removed `docs/migration-audit.md`, a stale point-in-time audit that still listed Gemini CLI as primary. `docs/agent-support.md` is the current record.
- Removed 5 prompt files that no runner referenced (`action-oriented`, `after-planning-flow`, `claude-suggested-it`, `i-know-what-sdd-means`, `skip-formalities`).
- Deliberately kept, per the audit:
  - `commands/` deprecation shims: they serve the primary Claude Code target, so they wait for a major release.
  - The `install.sh` log helpers: changing them is cosmetic only.

### One `.agents/skills` target, OpenCode, Windsurf retired
- Added `.agents/skills/`, a directory of per-skill links into `skills/`, for repo-level discovery. Codex ignores a symlinked skills directory, so `.agents/skills/` uses per-skill links (verified with Codex in a plain repo). The validator now checks that the links mirror `skills/`.
- Added `./install.sh --agents --global`, which links each skill into `~/.agents/skills/` (read by Codex, Devin, OpenCode, and other Agent Skills agents).
- Added experimental OpenCode support: native `.agents/skills` discovery plus a one-line `instructions` bootstrap that the installer prints.
- The bootstrap has one line for all Agent Skills agents (`$skill-name` in Codex, `/skill-name` in Devin CLI).
- Added an installer test. Smoke test 2026-09-28: OpenCode 1.18.29 discovery and `~` instructions bootstrap pass; codex-cli 0.156.1 discovers per-skill links in a plain repo and loads skills on request, but not a symlinked skills directory, and inside a Bearpaws checkout it lists the installed `bp:` plugin skills instead (`./install.sh --agents --global` is the recommended path for other projects; the global `~/.agents/skills` install has not been smoke-tested with Codex). These agents stay Experimental.
- The validator enforces the Agent Skills frontmatter spec (name format and folder match, description length).
- `--agents` never overwrites an existing entry it didn't link from this checkout (your directories and files, other skill packs, other Bearpaws checkouts); remove those by hand to relink.
- Removed `.windsurf/` and `.devin/skills/`. `.devin/hooks.v1.json` stays. Windsurf support removed; Windsurf users can use `--agents`.

### Breaking changes
- `--devin`, `--windsurf`, and `--all` removed; use `--agents --global`.
- `./install.sh` with no flags now errors (it used to install Devin + Windsurf).
- Upgrading from `--devin --global`: remove the old Bearpaws links in `~/.config/devin/skills/`, or Devin may list each skill twice.
- Experimental installers carry no stability promise; the Claude Code and Antigravity installation paths are unchanged.

### Skill content
- Reworded five skill descriptions as use conditions: brainstorming, finishing-a-development-branch, receiving-code-review, using-git-worktrees, and verification-before-completion. Brainstorming now begins with `Use when`.
- Trimmed the session bootstrap from 911 to 440 words. Its injected context fell from 6,334 to 3,161 bytes (about 1,520 to 759 tokens using the repository's byte-to-token estimate). The Red Flags table and required agent instructions remain.
- Replaced the bootstrap's all-caps and “1% chance” directives with a calm skill check rule.
- Changed brainstorming's design-doc step to commit only when the user or project permits commits without asking. In a fresh Codex-agent scenario, the old step caused an unrequested commit; the revised step left the doc uncommitted.
- Pre-change Claude triggering tests passed 12/13, then 13/13; the one failure was intermittent dispatching-parallel-agents. After the five description changes, those five skills triggered in two runs each (10/10). Explicit skill requests passed 4/4 before the bootstrap trim. Two unrelated simple prompts invoked zero skills before the trim. Full post-trim Claude behavior tests were not run because Claude usage was exhausted. The static validator, installer, and Antigravity adapter tests pass.
