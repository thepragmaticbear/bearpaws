# Bearpaws v2.5.1 — installer, hook, and version-tool fixes

This patch release fixes bugs found in review after v2.5.0. It changes the installer, the SessionStart hook's escaping, and `scripts/bump-version.sh`. No skill body changed, the Claude Code bootstrap payload is byte-for-byte the same, and no harness changed support tier.

## Installer (`install.sh`)

- **Failed steps now fail.** Each installer runs in a subshell with errexit on. Before, installers ran as `if !` conditions, so bash ignored `set -e`. Failed steps reported success, and a failed Antigravity copy could replace a working install and delete its backup.
- **Moved or re-cloned checkouts.** Reinstalling from a moved or re-cloned checkout now repoints that install's own stale skill links instead of skipping all of them. Ownership is recorded in `~/.agents/skills/.bearpaws-roots`. The installer owns only links into the current checkout or a recorded root. Other packs' links stay untouched, even same-named or dangling ones. Repoints are announced. Roots that nothing links to any more are pruned. A skipped dangling link that looks like a Bearpaws install made before roots were recorded gets a hint.
- **Grok rule cleanup.** `--grok` removes its staged rule file if writing or moving it fails.

## SessionStart hook

- `hooks/session-start` `\u`-escapes every control character JSON forbids, not just `\n`, `\r` and `\t`. A stray control byte in the bootstrap can no longer produce invalid JSON. Escaping uses shell builtins only, with no extra forks.
- `hooks/run-hook.cmd`: on Windows without bash, it now says on stderr why the bootstrap was skipped (still exit 0). On Unix, it fails loudly when no script name is given.

## Version tooling (`scripts/bump-version.sh`)

- Versions must be strict SemVer 2.0.0: anchored `X.Y.Z[-pre][+build]`, no leading zeros, no empty identifiers. The value goes to jq with `--arg` instead of being spliced into the jq program.
- `--audit` exclude entries that contain a slash are repo-relative paths. Before, grep only matched them by base name, so they did nothing. The audit reads NUL-separated file names and quotes the repo prefix, so `:` or glob characters in paths no longer break excludes or flag declared files.

## Tests and CI

- Regression tests for each fix in `tests/install/run-install-tests.sh`, `tests/hooks/run-hook-tests.sh` and the new `tests/bump-version/run-tests.sh`. The README uninstall snippet is now run by the installer tests.
- CI adds a bump-version job and runs the model-free benchmark, review-eval and native Plan Mode static tests.

## Docs

The README uninstall section and `docs/agent-support.md` describe the recorded-roots ownership.
