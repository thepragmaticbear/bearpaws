# Bearpaws v2.2.0 — Google Antigravity Support & Pace Control

This release introduces first-class Google Antigravity IDE support, retires active Gemini CLI support, and establishes **Pace Control** in the shared BearPaws bootstrap.

## Why 2.2.0

Google Antigravity IDE provides native support for Agent Skills and asynchronous subagents (`invoke_subagent`). Rather than running in a degraded single-session fallback mode as under the retired Gemini CLI adapter, BearPaws now runs as a native Antigravity plugin with isolated subagent workflows for planning, implementation, review, and parallel dispatch.

To prevent fast frontier models (like Gemini 3.8 Flash) from skipping deliberate reasoning at critical decision boundaries, this release introduces **Pace Control** into the shared bootstrap: **"Momentum does not waive gates."**

## What changed

### Google Antigravity IDE Support
- **Native Plugin Adapter**: Added `.antigravity/plugin.json` manifest and `.antigravity/rules/bearpaws.md` bootstrap rule.
- **Global Installer**: Added `./install.sh --antigravity --global`, staging real directory copies (no symlinks) to `~/.gemini/config/plugins/bearpaws/`.
- **Capability Mapping**: Added `skills/using-bearpaws/references/antigravity-tools.md` mapping Claude-style actions to native Antigravity capabilities (`view_file`, `write_to_file`, `replace_file_content`, `run_command`, `grep_search`, `find_by_name`, `invoke_subagent`).
- **Packaged Reviewer**: Packaged `agents/code-reviewer.md` with full adversarial review gates intact.
- **Native Subagents**: Mapped `subagent-driven-development`, `dispatching-parallel-agents`, and `requesting-code-review` to isolated Antigravity subagents.

### Shared Bootstrap: Pace Control
- Added `## Pace Control` to `skills/using-bearpaws/SKILL.md`:
  - Enforces: *Do not convert early confidence into immediate implementation.*
  - Mandates: *Momentum does not waive gates.*
  - Added Red Flag: *"I know where this is going"* is rationalization to stop and inspect.
- Replaced legacy Gemini CLI `activate_skill` text with native Antigravity Agent Skill instruction.

### Retired Gemini CLI Adapter
- Removed `gemini-extension.json`, root `GEMINI.md`, and `skills/using-bearpaws/references/gemini-tools.md`.
- Removed `gemini-extension.json` from `.version-bump.json`.
- Updated documentation and support matrices across `README.md`, `CLAUDE.md`, `AGENTS.md`, `docs/agent-support.md`, and `docs/skill-structure.md`.

## What did not change

- All 15 source skills in `skills/` maintain their core content and intent without Antigravity-specific forks.
- Claude Code behavior, hooks, and plugin definitions remain primary and fully preserved.
- Experimental support wiring for Devin for Terminal and Windsurf Cascade remains intact.
- Historical release notes and migration audit logs remain preserved as truthful historical records.
